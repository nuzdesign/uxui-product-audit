# uxui-product-audit
Skill di audit e controllo di metodo, valutazione UX/UI di un prodotto digitale esistente, un'analisi dei pain point o delle criticità di un sito, una verifica di accessibilità per prodotti digitali, website, web app, mobile app. Per prodotti esistenti pubblicati online o nuovi. Da utilizzare Claude - Claude Code - Codex.
Per qualsiasi audit, review o assessment di un prodotto digitale esistente, usa la skill `product-audit`. Non improvvisare un'analisi: la skill definisce intake obbligatorio, scala di severity e struttura del report.
